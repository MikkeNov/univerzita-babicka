# Univerzita pro babičku

Jednoduchá aplikace pro iPad nad webem vu3v.cz (Virtuální univerzita třetího věku) – velké písmo, velká tlačítka, video s pokračováním, předčítání studijních textů (i naskenovaných) a přehledné vyhodnocení testů.

Přihlašuje se přímo proti vu3v.cz (oficiální mobilní rozhraní Moodle). Heslo se nikam neukládá; přihlašovací klíč zůstává jen v zařízení.
